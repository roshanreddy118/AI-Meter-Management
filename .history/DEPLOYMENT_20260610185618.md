# Deployment Guide - Meter Tracker with Neon Postgres

## Prerequisites
- GitHub account (free)
- Vercel account (free)
- Neon account (free) - https://console.neon.tech

## Step-by-Step Deployment

### 1. Prepare Your Code for GitHub

```bash
# From your project directory
git add .
git commit -m "Update to Neon Postgres database"
git push origin main
```

### 2. Set Up Neon Database

1. Go to https://console.neon.tech
2. Sign up or login
3. Click "Create a project"
4. Name it: `meter-tracker`
5. Select region closest to you
6. Click "Create project"
7. Go to "Connection String" tab
8. Copy the connection string (looks like: `postgresql://user:password@host/dbname`)
9. Keep this ready - you'll need it for Vercel

### 3. Deploy to Vercel

1. Go to [vercel.com](https://vercel.com)
2. Sign up/login with GitHub
3. Click "New Project"
4. Select your "AI-Meter-Management" repository
5. Click "Import"
6. **Important**: Before deploying, add environment variables:
   - Click "Environment Variables"
   - Add variable: `DATABASE_URL`
   - Paste your Neon connection string from Step 2
   - Click "Add"
7. Click "Deploy"
8. Wait for deployment (2-3 minutes)
9. Your app is now live! ✨

### 4. Verify It Works

1. Open your deployment URL (something like `https://meter-tracker.vercel.app`)
2. You should see the glowing purple UI
3. The database warning should be gone
4. Try adding a property - it should save!

## Environment Variables Setup

When deploying to Vercel, you need one environment variable:

| Variable | Value | Where to get |
|----------|-------|--------------|
| `DATABASE_URL` | Your Neon connection string | https://console.neon.tech → Connection String |

Example:
```
postgresql://neon_user:password123@ep-blue-mountain-123456.us-east-1.neon.tech/meter-tracker
```

## Important: Connection String

Your Neon connection string looks like:
```
postgresql://[user]:[password]@[host]/[database]?sslmode=require
```

⚠️ **Important**: Make sure to copy the **full** connection string from Neon console

## Troubleshooting

### "Database not connected" message appears
- Check that `DATABASE_URL` is set in Vercel environment variables
- Verify the connection string is correct
- Go to Neon console → verify your project exists

### "Connection refused" or timeout errors
- Check Neon project is active (not paused)
- Verify connection string includes correct host and port
- Check firewall isn't blocking connections (usually not an issue)

### Tables not being created
- Check database user has create table permissions
- Try connecting directly: `psql $DATABASE_URL`
- Check Neon console logs for errors

### Can't find connection string in Neon
1. Log in to https://console.neon.tech
2. Select your "meter-tracker" project
3. Click "Connection String" tab
4. Copy the "Connection string" (not the pooling connection)
5. Paste into Vercel environment variable

## Local Development with Neon

To test locally with your Neon database:

1. Create `.env.local` file in project root:
   ```
   DATABASE_URL=postgresql://[your-neon-connection-string]
   ```

2. Run locally:
   ```bash
   npm run dev
   ```

3. Open http://localhost:3000

## Pausing/Resuming Database

Neon can automatically pause unused databases to save resources:

1. Go to https://console.neon.tech
2. Select "meter-tracker" project
3. Click "Settings"
4. Set "Autosuspend delay" (e.g., 5 minutes)
5. Database resumes automatically when accessed

## Resetting Database

If you need to start fresh:

### Option 1: In Neon Console
1. Go to https://console.neon.tech
2. Select "meter-tracker" project
3. Click "SQL Editor"
4. Run: `DROP TABLE IF EXISTS meter_readings; DROP TABLE IF EXISTS properties; DROP TABLE IF EXISTS settings;`
5. Next app reload creates fresh tables

### Option 2: Delete and recreate project
1. In Neon console, delete "meter-tracker" project
2. Create new project
3. Update DATABASE_URL in Vercel
4. Redeploy
